## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 рекомендуется этот вариант.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/HeightHammerScoop/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно пропустить.

4. Извлеките файлы в путь без кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для установки автозапуска выберите **`service.bat`** -> `Install Service` -> нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящий**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - устанавливает выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб.
  - **`Check Status`** - показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** - меняет режим обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние включения или выключения отображается в скобках.
  - **`IPSet Filter`** - переключает режим обхода ресурсов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках выводится текущий режим:
    - `none` - ни один IP не проверяется
    - `loaded` - IP проверяется по списку
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** - включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** - заменяет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновляет hosts <ins>для восстановления веб-версии Telegram и соединения с голосовым чатом Discord.</ins>
  - **`Check for Updates`** - вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В конце можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает работоспособность приложения.
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который виден на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/HeightHammerScoop/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер.

### Не работает телеграм (веб версия)

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое открывшегося блокнота.
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранены.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/HeightHammerScoop/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут терять работоспособность.**
> Одна и та же стратегия может работать некоторое время, а затем перестать работать после её обнаружения.
> Здесь собрано много вариантов обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках.

- Проверьте наличие адреса нужного ресурса в списках доменов или IP.

- Испытайте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- См. [#765](https://github.com/HeightHammerScoop/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/HeightHammerScoop/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы.
- Попробуйте разные `general`-скрипты. Проверяйте доступ к интернет-ресурсам: если они не открываются, закройте программу через значок замка на панели задач и запустите другую стратегию.
- После выбора рабочей стратегии установите её в автозапуск через `service.bat` -> `Install Service`.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows определите имя службы. Открыть командную строку можно через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив найденное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия перестала работать, проверьте все остальные.
- См. также [#251](https://github.com/HeightHammerScoop/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её.
- Выполните `service.bat` -> `Run Diagnostics`, затем очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, её можно использовать.
- Если Discord не открывается и в браузере, снова проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/HeightHammerScoop/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/HeightHammerScoop/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Следует учитывать, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/HeightHammerScoop/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Сообщите о ней [здесь](https://github.com/HeightHammerScoop/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
